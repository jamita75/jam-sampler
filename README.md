# JAM SAMPLER — campionatore gratuito per PC / free keyboard sampler for Windows

![JAM SAMPLER](https://www.creaitivity.it/wp-content/uploads/2026/10/jam-sampler-campionatore-gratuito-per-pc.jpg)

**La tastiera del PC diventa un campionatore.** Un suono per ogni tasto, pronto per suonare dal vivo.

## ⬇ Download
**[Scarica JamSampler.exe](https://github.com/jamita75/jam-sampler/releases/latest)** — Windows 10/11, nessuna installazione.

> Al primo avvio Windows SmartScreen può mostrare "PC protetto": il programma non ha firma digitale. Clicca **Ulteriori informazioni → Esegui comunque**.

## Cosa fa
- Un pad per ogni tasto della tastiera (numeri, lettere, punteggiatura)
- Tre modalità per pad: **GATE** (suona finché tieni premuto), **LOOP** (ripete), **HOLD** (suona fino in fondo)
- Velocità/intonazione con la rotella, volume con Shift + rotella, taglio del silenzio con un clic
- **REGISTRA** quello che suoni
- **Misura BPM** e **Sincronizza** tutti i campioni allo stesso tempo
- **Salva kit / Carica kit** per ritrovare il tuo set
- Formati: WAV · MP3 · FLAC · OGG

Guida completa: **[creaitivity.it/progetti/jam-sampler](https://www.creaitivity.it/progetti/jam-sampler/)**
